# PaperNotes

Windows向けの付箋アプリです。複数の付箋をデスクトップに表示し、メモやタスクを管理できます。データはローカルに保存され、アカウント登録は不要です。

## 主な機能

- 複数の付箋を作成・編集、自動保存
- 太字、下線、ハイライト、文字サイズの変更、チェックリスト
- 付箋の検索・分類
- 折りたたみ、半透明表示、最前面への固定
- タスクトレイ常駐、ショートカットキーの設定
- 日本語・中国語・英語の表示切り替え

付箋のウィンドウを閉じても、内容は削除されません。アプリを終了する場合は、タスクトレイのメニューから終了してください。

## 動作環境

- Windows 10 / 11
- .NET 8 Desktop Runtime

ソースコードからビルドする場合は、.NET 8 SDKが必要です。

## ビルド・テスト

リポジトリのルートで実行します。

```powershell
# ビルド・テスト・配布用ZIPの作成
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# テストのみ
dotnet run --project tests\Stickies.Tests.csproj -c Release
```

ビルド結果は `outputs/PaperNotes` に出力されます。既存の出力内容は上書きされます。

## データの保存

保存先は `%LOCALAPPDATA%\PaperNotes` です。クラウド同期には対応していません。

付箋ごとにJSONファイルへ保存します。一時ファイルへの書き込み後に既存ファイルを置き換え、読み込みに失敗した場合はバックアップからの復元を試みます。

## 実装で工夫した点

### 書式が壊れても本文を残す

本文はプレーンテキストと書式情報を分けて保存しています。書式情報を読み込めない場合も、本文を表示できるようにしました。

### 貼り付け時は文字の保持を優先する

Wordなどからの貼り付けでは、書式情報の解析結果とクリップボードの文字列を照合します。不一致がある場合はプレーンテキストに切り替え、文字の保持を優先します。この場合、元の書式は保持されません。

この処理は模擬クリップボードデータによる自動テストの対象にしています。
