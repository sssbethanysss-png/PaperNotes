# 纸间 UI 文本待翻译清单

> 提取自当前中文 UI（标题栏 / 设置 / 快捷键改版后）。**尚未实现语言切换**；日语、英语列留空，待确认后再接入。

- 源语言：zh-CN
- 计划目标语言：ja（默认）、en
- 品牌：UI「纸间」；技术标识 PaperNotes

## 迁移与快捷键说明

- 旧版全局快捷键仅硬编码注册，**从未写入** settings.json。
- 升级后若缺少 `HotkeyCreate` / `HotkeyToggleAll`，视为用户未配置 → **不绑定**，界面显示「未设置」。
- 这不是清空用户自定义（历史上不存在可区分的用户快捷键配置）。

## 需要确认的术语 / 含义

- 品牌「纸间」在日语/英语中是保留汉字、音译，还是另取名？
- 托盘文案「纸间 · PaperNotes」是否在各语言都保留英文副标识？
- 颜色名（浅黄/樱粉等）是意译还是改为色号/通用色名？
- 「任务清单」在日语中用「チェックリスト」还是「タスク」？
- 「未设置」用于快捷键空状态，是否与表单校验「未填写」区分用词？
- 系统保留名「全部」「未分类」是否必须与页签文案完全一致（含用户命名冲突校验）？

## 疑似遗漏或无法静态确认

- Windows 原生对话框按钮（是/否/确定）由系统语言决定，未收录。
- ex.Message / UnauthorizedAccessException.Message 等系统异常原文会拼入部分错误提示。
- 用户便签正文、分类名称、搜索关键字属于用户内容，不收录。
- 快捷键组合显示（如 Ctrl+Shift+N）为键名格式化结果，修饰键英文缩写是否本地化需确认。
- LoadWarning 富文本提示会显示在便签状态区（若触发）。
