# 纸间 · PaperNotes 0.2.10

## 升级与启动

如果旧版正在运行，先在系统托盘右键选择「退出纸间」，再双击 `outputs/PaperNotes` 文件夹里的 `PaperNotes.exe`。只关闭索引不会退出旧版；旧版仍在运行时，新版会依照单实例规则唤回旧版。

新旧版本共用 `%LOCALAPPDATA%\PaperNotes`，已有便签无需导入或迁移。测试数据只在项目 work 中。建议升级前退出应用后备份整个正式数据目录。

分发请使用 `outputs/PaperNotes-Windows.zip`，或复制整个 `outputs/PaperNotes` 文件夹，不能只复制 exe。运行需要 .NET 8 Windows Desktop Runtime，本机已经安装。
（以上路径以仓库根目录为基准，与当前 `build.ps1` 输出一致。）

## 单张便签

- 顶部 `A` 设置格式，`···` 提供浮在所有窗口之上、半透明、固定到索引顶部、颜色、打开索引、隐藏与删除；`−` 最小化，`×` 隐藏。新建便签通过索引、托盘或全局快捷键。
- 拖动顶部空白区域移动便签；四边和四角均可缩放。
- 高度小于 96 DIP 时，顶部按钮自动消失，顶部保留约 10 DIP 透明拖动条，最低可缩到 40 DIP；拉高便签后自动恢复。此时右键正文也能访问格式和便签菜单。
- 便签窗口拖到屏幕边缘不会触发 Aero Snap / 半屏贴靠 / 自动最大化，尺寸仅在手动缩放边框时改变。
- 「半透明」开启后整个窗口透明度为 0.85；每张便签独立保存，新便签默认关闭。
- 「浮在所有窗口之上」持续位于普通窗口上方，其他应用仍可获得输入焦点；不保证覆盖安全桌面、UAC、独占全屏和其他更高层的置顶窗口。
- 常规自动保存没有状态文字。保存失败会显示错误并重试，恢复后提示消失。

## 文字格式

选中文字后，`A` 菜单可设置粗体、下划线、文字高亮（浅黄荧光笔），以及字体变大/变小（13、16、20、26 四档）。格式应用后选区保持，可连续点多项。未选中文字时，格式只应用于之后输入的文字。再次点击「文字高亮」可取消高亮。

Ctrl+B / Ctrl+U 分别对应粗体、下划线。复制、粘贴、剪切、全选、撤销、重做继续使用 Windows 常用快捷键。输入法使用原生 WPF RichTextBox。

格式自动保存并在重启后恢复（新保存为 XAML 富文本，旧 RTF 仍可打开）。旧版纯文本便签保留原文。富文本损坏时会回退到仍然保存的完整正文。

## 索引与选择

操作按钮下方有一行分类标签：`全部`、`未分类`，以及自己添加的分类。点击某个分类只显示该分类的便签；`全部`显示所有便签。标签上的数字是这个分类里的便签数量，例如 `研究 (8)`。标签较多时可以横向滚动。右侧 `＋` 用来新建分类；在自定义分类上右键可以改名称、换主题色，或删除分类。删除分类不会删除便签，这些便签会回到未分类。

新建便签时，会归入当前选中的分类。当前是 `全部` 或 `未分类` 时，新便签就是未分类。已有便签可以在列表里右键，通过「分类」移到别的分类；多选时会一起移动。

卡片左侧色条：已经分类的便签使用该分类的主题色；未分类便签仍使用便签自己的颜色。

固定便签排在前面；隐藏便签仍在列表中。窗口置顶与索引固定互相独立。

普通单击打开或激活便签。按住 Ctrl 点击可增减选中项，Shift 点击可选择连续范围；多选不会打开一堆便签。右键单张记录可以删除，删除需要确认且不能撤销。搜索范围是当前分类里的全部正文，不包含内部格式代码。改变搜索条件会清除不在当前结果里的选中项。

## 托盘与快捷键

| 操作 | 快捷键 |
| --- | --- |
| 全局新建便签 | Ctrl + Shift + N |
| 全局隐藏 / 显示便签 | Ctrl + Shift + H |
| 索引内搜索 / 新建 | Ctrl + F / Ctrl + N |
| 粗体 / 下划线 | Ctrl + B / U |
| 复制 / 粘贴 / 剪切 / 全选 | Ctrl + C / V / X / A |
| 撤销 / 重做 | Ctrl + Z / Y |

快捷键冲突会提示，托盘菜单仍可使用。双击托盘图标打开索引；右键可新建、显示、隐藏和退出。批量显示保留单独点 × 隐藏的便签偏好。

## 保存、设置与备份

正文和格式停止变动 400ms 后自动保存，窗口移动结束、隐藏及退出时也保存。内容、位置、大小、颜色、置顶、半透明、隐藏状态重启后恢复。原子写入、上一版 `.bak` 备份和损坏文件恢复保留。

强制结束或断电仍可能丢失尚未触发保存的输入；正常退出会阻止丢弃保存失败的便签。

设置在索引右上角 `⚙`，提供界面语言、默认颜色、默认置顶、全局快捷键和开机启动。语言选项为日本語 / 简体中文 / English；首次启动或旧配置缺少语言字段时默认日语，保存后立即切换并在下次启动恢复，取消不改语言。语言切换只影响界面文案，不翻译便签正文、分类名称或数据路径。默认颜色与置顶只影响新便签。开机启动默认关闭；如果旧版已开启，升级后需要在设置中关闭再开启一次，更新启动路径。

数据目录为 `%LOCALAPPDATA%\PaperNotes`，其中 `notes` 是便签，`settings.json` 是偏好。删除程序文件夹不删除此目录。
